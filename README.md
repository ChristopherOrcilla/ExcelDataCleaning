# ExcelDataCleaning
Excel data cleaning portfolio piece

What was the problem?
The client’s customer order export contained 726 records with inconsistent formatting, duplicate entries, mixed date and currency formats, inconsistent product and category names, missing values, malformed email addresses, and conflicting order records. These issues made the file harder to filter, analyze, and use for reliable reporting.
What did I do to fix it?
I created a structured cleanup process that preserved the original source data while building a standardized master dataset. I cleaned and normalized names, locations, products, categories, order statuses, payment methods, dates, phone numbers, prices, discounts, and order IDs. I removed confirmed duplicate records, used lookup-based rules to standardize recurring values, and separated unresolved issues into an exceptions list instead of making unsupported assumptions.
The final workbook included the original raw data, the cleaned dataset, lookup tables, a cleaning log, and an exceptions sheet for records that still required review.
What tools/techniques did I use?
I completed the project in Microsoft Excel using:
•	Excel Tables
•	XLOOKUP
•	TRIM, PROPER, SUBSTITUTE, IF, IFERROR, and other cleaning formulas
•	Conditional Formatting
•	Filters and sorting
•	Duplicate analysis
•	Lookup tables for standardization
•	Data validation and quality checks
•	Structured documentation through a cleaning log and exception tracking
